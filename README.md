# E-Commerce Store

## Project Overview

This is a full-stack E-Commerce Store developed as part of the CodeAlpha Internship Task 1.

The application allows users to register and log in, browse products, view product details, add products to a shopping cart, and place orders.

An admin panel is also included for managing products.

## Features

- User Registration
- User Login
- Product Listing
- Product Details
- Shopping Cart
- Increase / Decrease Quantity
- Remove Products from Cart
- Order Processing
- Order History
- Admin Panel
- Add Products
- Delete Products
- SQLite Database

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- SQLite
